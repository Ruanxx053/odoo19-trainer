# Odoo 19 认证训练器（本地小工具）

把 `认证备考/Odoo19/` 里的题库和教程编译成一个本地网页应用：点选项判对错、自动收错题、统计薄弱点、一键生成 AI 分析材料、随题跳教程。

## 打开方式

1. **推荐**：双击 `打开学习工具.command`（会起一个本地小服务并自动打开浏览器；关掉终端窗口即停止服务）。
2. 直接双击 `index.html` 也能用，但 **Safari 可能不允许 file:// 下保存进度**，建议用 Chrome / Edge。

进度数据存在浏览器 localStorage 里，换浏览器或清缓存会丢；想备份就点「统计 → 复制全部学习数据」（也可用「导出 / 导入数据」把进度搬到手机）。

## 手机上用（iPhone / iPad）

训练器已经做成 **PWA**：只要用 **https 网址**打开过一次，点「分享 → 添加到主屏幕」，之后**完全离线可用**（练习、错题本、模拟考、教程全文都在本地）。

**为什么必须是 https**：离线靠的是 Service Worker，而浏览器只允许它在**安全上下文**（https / `localhost` / `127.0.0.1`）里注册。局域网 IP（`http://192.168.x.x`）和 `file://` 都**不满足**，所以在手机上走局域网只能"在线用"，进了地铁就没网。

### 步骤

1. 把整个 `学习工具/` 文件夹原样上传到一个免费静态托管（任选其一）：
   - **GitHub Pages**：新建仓库 → 上传这些文件 → Settings → Pages → 选分支 → 得到 `https://<用户名>.github.io/<仓库>/`
   - **Netlify Drop**：打开 app.netlify.com/drop，把文件夹拖进去 → 立刻得到 https 网址
   - **Cloudflare Pages**：同上
2. 手机上用 **Safari** 打开这个 https 网址（第一次需要联网）。
3. 点底部 **分享按钮 → 添加到主屏幕**，起个名字（如"Odoo训练器"）。
4. 从主屏幕打开一次，让它把资源缓存下来（看到题目就说明好了）。
5. 之后**开飞行模式也能用**。

> 图标、启动方式都已配好（`manifest.webmanifest` + `sw.js` + `icon-180.png`）。

### 电脑 ↔ 手机 同步进度

进度存在各自浏览器的本地存储里，**不会自动同步**。在 `统计 → 数据` 里：
- **导出为文件（.json）** → 手机上会存进"文件"App
- **导入学习数据** → 选中那个文件即可覆盖过来

### 改了题库怎么让手机更新

重新跑 `parse_bank.py` / `build_tutorials.py` 并重新上传后，**把 `sw.js` 里的 `VERSION` 改一下**（如 `v1` → `v2`），手机上再打开一次就会拉到新版本。

## 功能

| 视图 | 能做什么 |
|---|---|
| 首页 | 已练进度、正确率、待攻错题、薄弱点 Top 4、按每天 40 题估算剩余天数 |
| 练习 | 按模块/难度/范围出题；点选项**立刻判分**（正确=绿框，错误=红框并同时标出正确答案与你选的答案）；每题都给「解析 / 干扰项 / 出处」和「打开对应教程」；可收藏、可标记已掌握；做完一轮给小结，可一键复习本轮错题 |
| 模拟考 | 自定义题量/时长/模块，也可一键「全真模考 120 题 / 90 分钟」；倒计时、答题卡、标记待复查；交卷按**答对 +1、答错 −0.5、空答 0** 计分并对照 70% 及格线，错题自动进错题本 |
| 错题本 | 按模块分组、按错得次数排序；可展开看正确答案与出处；一键「只练错题」；标记「已掌握」后移出 |
| 统计 | 分模块正确率与进度条、薄弱考点排行、最近模拟考成绩；**AI 薄弱点分析**：一键生成含统计+错题样本+对应教程的分析材料并复制（也可直连 OpenAI 兼容 API） |
| 教程 | 目录里 **42 篇**文档（`00`–`41`）全文阅读，支持全文搜索并跳转定位；教程里的 Mermaid 时序图/流程图直接渲染（共 44 张图） |

**快捷键**：练习中 `1`–`4` 选答案、`Enter` 下一题、`F` 收藏；模拟考中 `1`–`4` 作答、`←/→` 翻页。

## 改了 md 之后怎么更新

在 `学习工具/` 目录里执行：

```bash
python3 parse_bank.py        # 重新编译题库 → bank.js
python3 build_tutorials.py   # 重新打包教程 → tutorials.js
```

然后在浏览器里刷新页面即可（`Cmd+R`）。

## 说明与边界

- 应用是**纯前端、无依赖、默认离线**：不联网也能用；只有点「直连 API 分析」才会发网络请求（file:// 下可能被 CORS 拦，建议用「生成并复制」把材料发给 AI）。
- Mermaid 需要同目录的 `mermaid.min.js`；缺失时时序图会退化成代码块显示，其余功能不受影响。
- 题库内容来自本目录备考文档（依据 Odoo 19.0 官方文档整理），**不是官方真题**。
